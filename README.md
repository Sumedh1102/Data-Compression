# Data-Compression
The Data Compression project is a C-based application that reduces the size of strings by encoding repetitive characters as a character followed by a count, and can also decompress the string back to its original form.


# Features
	•	Compresses strings by replacing consecutive duplicate characters with a count and character.
	•	Decompresses the compressed string back to its original form.
	•	Simple implementation using standard C libraries.

# How It Works
	1.	The user inputs a string for compression.
	2.	The program compresses the string by counting consecutive repeated characters and storing them as a single character followed by the count.
	3.	The compressed string can be decompressed to its original form.

# Example Workflow
	1.	Compression:
	•	The program reads the input string and compresses it by replacing consecutive characters with a number (e.g., “aaabb” becomes “a3b2”).
	2.	Decompression:
	•	The program reverses the process and restores the original string.
